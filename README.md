# Здай свій мерч

Навчальний проєкт. Співвиконавці: Лебідь Данило та Бурко Михайло.

## Запуск
Відкрийте index.html у сучасному браузері (Chrome, Edge, Firefox). Встановлювати пакети не потрібно. Для локального HTTP: `python -m http.server 8080` у каталозі проєкту, далі http://localhost:8080.

## Робота
Вкажіть кількість виробів, оберіть варіант переробки, введіть назву компанії. Натисніть «Сформувати заявку», потім «Друк / зберегти PDF» і виберіть системний принтер «Зберегти як PDF». Email і телефон необов’язкові. Кнопка копіювання використовує Clipboard API; браузер може її обмежити для локальних файлів. У такому разі текст можна виділити вручну.

Програма не надсилає листи: немає адреси реальної майстерні й поштового сервера. Для надсилання збережіть PDF і додайте його до листа вручну. Введені дані не зберігаються після перезавантаження. Ціни є навчальними.

## Модулі
- src/domain.js: бізнес-правила, валідація кількості, підсумки.
- src/application.js: сценарії розрахунку і створення заявки.
- src/catalog.js: незмінна конфігурація каталогу.
- src/view.js: DOM-адаптер, безпечний вивід через textContent.
- src/export.js: адаптер друку і буфера обміну.
- src/main.js: головний компонент, створення та з’єднання залежностей.

Класичні скрипти використано для запуску через file://. Порядок завантаження визначено в index.html. Модулі публікують лише заморожені API в просторі Merch*. CommonJS-експорт бізнес-модулів забезпечує тести Node.js без додаткових залежностей.

## Перевірки
Потрібен Node.js: `node --test tests/*.test.cjs`.
Ручна перевірка: 100 футболок і 5 банерів у шопери -> 220 аксесуарів, 10 100 грн. Нуль усіх кількостей не дозволяє створити заявку. Зміна полів приховує попередню заявку. HTML у назві компанії має показуватись як звичайний текст.

## Ролі
Данило: логіка і тестування. Михайло: вимоги, інтерфейс і заявка. Це навчальний розподіл відповідальності; початковий код підготовлений за допомогою Codex. Історія попередніх змін відсутня, тому частоту змін функцій визначити неможливо.
